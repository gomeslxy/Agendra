# 🧱 Stack Técnica & Arquitetura

O Agendra utiliza uma stack moderna e de alta performance para garantir escalabilidade e UX premium.

## 🧱 Frontend
- **Framework**: Next.js 15 (App Router).
- **Styling**: TailwindCSS v4 + Framer Motion 12.
- **Design System**: "Liquid Glass" (vidro, sheen, aurora).

## 🧱 Backend & Infra
- **DB/Auth**: Supabase (PostgreSQL).
- **Realtime**: Supabase Realtime para Inbox e Leads.
- **Runtime**: Node.js 20+ no Edge (onde disponível).

## 🧠 Inteligência Artificial
- **Engine**: Gemini 2.0 Flash (Google AI).
- **Protocolo**: Tool Calling + Loop Agêntico.
- **Contexto**: `lib/ai/engine.ts`.

## 🔗 Integrações
- **Messaging**: WhatsApp Cloud API (Meta).
- **Calendário**: Google Calendar API (OAuth2 Flow).
- **Pagamentos**: Stripe API.
