# 💎 UI Component Skill

When working in `components/`:
1. **Liquid Glass**: Apply `.glass` utility. Use subtle gradients and hairlines.
2. **Motion**: Every interactive component should have a Framer Motion state (hover, tap, entry).
3. **Typography**: Use `Inter Tight` for headings and `Inter Italic VF` for emphasis.
4. **Consistency**: Use the design system tokens defined in `globals.css`.
